# Documentation technique de Cirrus

## Comment accéder au Swagger ? 

1. Il faut générer la documentation (seulement sur les environnements locaux non conteneurisés).
````bash
npm run generateSwagger
````
2. Rendez vous sur la route /doc 

Dans le cas de l'environnement de Recette, il est accessible à cette adresse : [Swagger Recette](https://api.crrs.cloud/doc)
